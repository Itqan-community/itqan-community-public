# Itqan Preview Cards

بطاقة معاينة مُولَّدة لكل نقاش، تُرسم في متصفح حقيقي، فيخرج النص العربي فيها سليم الاتجاه والوصل والقياس.

عند مشاركة رابط نقاش على منصات التواصل، تلتقط المنصة عنوان الصفحة ووصفها وصورتها من وسوم Open Graph. كانت الصورة المعلنة إما شعار المنتدى، وإما صورة يرفعها المشرف يدويًا لكل نقاش. وتضيف هذه الإضافة بطاقة ‎1200×630‎ لكل نقاش مرئي على تصميم واحد: الشعار في طرف البطاقة، وتحته شريط التمييز ثم النص التعريفي، ثم عنوان النقاش في سطر واحد، ومقتطف من المشاركة الأولى في سطرين، وخط فاصل، وفي الأسفل اسم الكاتب وصورته في طرف، والتاريخ وعدد الردود في الطرف الآخر. ولكل عنصر منها مفتاح إظهار وإخفاء، ولخلفية البطاقة صورة يرفعها المشرف، ولألوان عناصرها لوحة يضبطها من لوحة الإدارة.

## كيف تعمل

1. يمر طلب صفحة النقاش على محرّك `v17development/flarum-seo`، فيضيف وسوم التواصل الاجتماعي المعتادة.
2. تضيف الإضافة بعده وسم `og:image` مطلقًا، مصحوبًا بالأبعاد والنوع والنص البديل. ويحمل عنوان الصورة بصمة محتوى النقاش، فكل تعديل يغيّر العنوان.
3. عند أول طلب للصورة يرسمها Chromium بلا واجهة، ثم تُخزَّن في `storage/preview-cards/`، وتُقدَّم بعد ذلك من القرص.
4. كل رد جديد يغيّر عدد الردود وتاريخ آخر رد، ومن ثَمّ تتغير بصمة البطاقة، فيُرسم منها إصدار جديد عند الطلب التالي.
5. إن تعذّر الرسم لأي سبب، قُدِّمت بطاقة العلامة بدلًا منها، فلا يصل الزاحف إلى صورة مفقودة.

## لوحة الإعدادات

صفحة الإعدادات في لوحة الإدارة خمسة أقسام:

| القسم | ما فيه |
| :--- | :--- |
| عناصر البطاقة | مفاتيح إظهار وإخفاء: الشعار، واسم المنتدى، والنص التعريفي، ووسم القسم، والمقتطف، واسم الكاتب، وصورة الكاتب، وتاريخ النشر، وعدد الردود، وتاريخ آخر رد. |
| الألوان | الخلفية، ولون التمييز، ولون العنوان، ولون المقتطف، ولون البيانات، ولون الوسم. ويُترك لون التمييز فارغًا ليتّبع لون قالب المنتدى. |
| الصور | رفع شعار خاص بالبطاقة أو حذفه، ورفع خلفية أو حذفها. تُحفظ الصور في مجلد أصول المنتدى. |
| الهوية واللغة | الاسم بالعربية، والاسم بالإنجليزية، والنص التعريفي بالعربية والإنجليزية، ولغة البطاقة. ويُعرض شعار البطاقة، ثم شعار المنتدى، ولا يُعرض الاسم إلا عند غيابهما أو إخفائهما. |
| الصيانة | زر مسح البطاقات المولَّدة، ويذكر عددها والمساحة المحرَّرة. |

## العربية

- النص يبقى في ترتيبه المنطقي كما كتبه صاحبه: لا يُقلب، ولا تُستبدل حروفه بصورها في كتلة التوافق `U+FE70–FEFF`.
- تسافر الخطوط مع الصفحة نفسها داخل `data:`، فلا يحتاج الرسم إلى شبكة ولا إلى خطوط النظام.
- يختار Chromium الخط لكل محرف حسب `unicode-range`، فيبقى الاسم اللاتيني داخل الجملة العربية بالخط نفسه.
- وللعربية مقياس مختلف: مقاس أصغر، وتباعد أسطر أوسع، وقيمة كل منهما مضبوطة في القالب.
- تُقرأ الخطوط من إضافة `itqan-typography` إن كانت مثبَّتة ومفعَّلة، فإن لم تكن فمن النسخ المضمَّنة في هذه الإضافة. وبصمة الخطوط تدخل في مفتاح التخزين، فتغيُّر ملفات الخطوط يبطل البطاقات القديمة، وتبدّلُ المصدر بالملفات نفسها لا يبطلها.

## المسارات والوسوم

| | |
| :--- | :--- |
| صفحة النقاش | `/d/{id}-{slug}` |
| صورة البطاقة | `/og/d/{id}-{hash}.png` |
| اسم المسار | `itqan-preview-cards.image` |
| مفتاح التخزين | أول 12 خانة من `sha256` لمحتوى البطاقة وبصمة الخطوط والإصدار |
| وسوم الصورة | واحد فقط لكل من `og:image` و`twitter:image`، ومعهما `og:image:width`، و`og:image:height`، و`og:image:type`، و`og:image:alt`، و`twitter:image:alt` |

## الأوامر

| الأمر | ما يفعله |
| :--- | :--- |
| `itqan-cards:brand` | يرسم بطاقتي العلامة بالعربية والإنجليزية ويكتبهما في `assets/fallback`. |
| `itqan-cards:warm` | يولّد بطاقات النقاشات النشطة مسبقًا. |
| `itqan-cards:prune` | يحذف البطاقات التي جاوزت مدة الاستبقاء. |
| `itqan-cards:doctor` | يفحص المتصفح والخطوط والذاكرة والإعدادات. |

## التطوير

```bash
cd packages/itqan-preview-cards/js && npm install && npm run build
docker compose exec web su -s /bin/bash www-data -c 'php flarum assets:publish'
docker compose exec web su -s /bin/bash www-data -c 'php flarum itqan-cards:doctor'
docker compose exec web su -s /bin/bash www-data -c 'php flarum itqan-cards:warm --limit 20'
docker compose exec web su -s /bin/bash www-data -c 'php flarum itqan-cards:prune --days 30'
```

المتصفح مطلوب للرسم الحقيقي. وصورة `web` في `.docker/Dockerfile` تُنصّب `chromium` وخطوط Noto؛ ودون المتصفح تُقدَّم بطاقة العلامة وحدها.

## ملاحظة عن التركيب في هذه البيئة

لا يستطيع `composer update` أن يحلّ الحزم، لأن مستودع حزمة اللغة العربية الخاص لم يعد متاحًا. لذلك روعيت هذه الحزمة في `vendor/` يدويًا، وأُضيف مدخلها إلى `vendor/composer/installed.json`، ثم أُعيد توليد التحميل التلقائي بـ `composer dump-autoload`. وتفاصيل التصميم والخطة كاملة في `docs/design.md`.
